# NIMO

This is an open-source project that ultimately aims to make advanced wealth management and capital modelling transparent, accessible, and agentically optimised.

The codebases is a financial budgetting study that may be developed for personal use but is primarily a personal sandbox for practices analytical methods on financial reports. The aim of the project is to develop:

1. Seeded random statement generation that mimics basic user actions and behaviours.
2. User inputable CSVs. Duplicate handling, user database formation.
3. Surface-level analysis of profiles containing multiple accounts.
4. Categorisation and tag-specific metric aggregation.
5. Advanced budgetting and goal setting features
6. Agentically optimised advice and report generation.
7. Client-friendly dashboard.
